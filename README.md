# Hastane-Ariza-Zimmet-Projesi

# Kurum içi donanım arızalarının ve personel zimmetlerinin web üzerinden takip edileceği otomasyon projesi

# İlk aşamada sistemin gereksinim analizi yapılacak ve veritabanı tablolarının taslağı çıkarılacak

# Arayüz tasarımı Fırat Üniversitesi Araştırma Hastanesi kurumsal standartlarına uygun, sade ve kullanıcı dostu (responsive) olacak

# Arka uç (Backend) geliştirmeleri için PHP, veritabanı yönetimi için ise MySQL tercih edilecek

# Ön yüz (Frontend) tarafında HTML, CSS ve JavaScript teknolojileri kullanılarak dinamik sayfalar oluşturulacak

# Sisteme 3 farklı yetki seviyesinde kullanıcı rolü (Sistem Yöneticisi, Teknik Personel, Kurum Personeli) eklenecek
